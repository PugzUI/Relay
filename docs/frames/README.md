These frames are captured from the functioning Relay UI using the isolated browser fixture. They are not static mockups.

| Frame | State | Viewport intent |
|---|---|---|
| `01-initial-topology.png` | Connected snapshot with a committed record and active path | Desktop first impression |
| `02-filtered-transformation.png` | Deliberate no-match topology filter | Signature interaction result |
| `03-mobile-composition.png` | Connected narrow layout | Responsive recomposition |
| `04-mobile-board-lane.png` | Narrow layout scrolled to the board/inspector lane | Lower-page responsive continuity |

The frame set is complemented by state captures in `docs/captures/` for disconnected, denied, cached, empty, and 200% text conditions.
